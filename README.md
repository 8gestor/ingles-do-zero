# Inglês do zero ao avançado (nome provisório)

Site para estudar inglês do **zero ao avançado**: trilha por níveis, leitura, escuta, fala, escrita e revisão espaçada, com os dados do aluno guardados só no próprio aparelho.

**Estado: em planejamento (fase F0).** Não há site no ar e **ainda não há domínio próprio** (decisão do autor: só depois do projeto pronto). Repositório **privado**.

Este projeto nasceu da aba "Estudo de Inglês" do livro *Data Double* (`8gestor/voce.algoritmo`, https://vocealgoritmo.com.br/). Os dois projetos são **independentes**: o livro continua como está.
